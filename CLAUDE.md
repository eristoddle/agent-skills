# agent-skills

Public repo of standalone agent skills (`skills/<name>/SKILL.md`). Each skill must work on its own: no dependencies on other skills in this repo, no assumptions about one person's machine.

- Keep skills generic: no absolute personal paths, usernames, emails, private tool names, or references to skills not in this repo.
- Frontmatter needs `name` and `description`; the folder name matches `name`.
- Prose in markdown files is one paragraph per line, no hard wrapping.
